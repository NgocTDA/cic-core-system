PHẦN 3: GHI CHÚ KIẾN TRÚC NAVIGATION
================================================================================

1. NGUYÊN TẮC TỔ CHỨC MENU
   ─────────────────────────────────────────────────────────────────
   · T1 (Data Asset) là trung tâm — menu chính, luôn mở sẵn
   · T2A / T2B là phần mở rộng trong context của một Asset cụ thể
     → Không nên tách T2A/T2B thành sidebar riêng biệt
     → Hiển thị như tab / section bên trong trang Asset
   · T3A (Glossary) có menu riêng do có luồng độc lập
     (tạo, phê duyệt, xuất file)
   · MX (Lineage, Relations) là công cụ — menu phụ hoặc
     accessible từ mọi trang qua button "Xem Lineage"

2. DYNAMIC BADGES (số hiển thị trên menu)
   ─────────────────────────────────────────────────────────────────
   pendingCount        : Số asset đang chờ phê duyệt (Owner nhận)
   unmappedBACount     : Số BA chưa có TA nào được map
   newDiscoveryCount   : Số TA mới phát hiện từ auto-discovery
   pendingSchemaCount  : Số schema thay đổi chờ review
   pendingTermCount    : Số thuật ngữ đang chờ phê duyệt
   staleTermCount      : Số thuật ngữ chưa review > 1 năm

   → Gọi API 1 lần khi load menu, polling mỗi 5 phút
   → Badge màu đỏ khi count > 0

3. PHÂN QUYỀN HIỂN THỊ MENU
   ─────────────────────────────────────────────────────────────────
   Role              Hiển thị menu
   ─────────────────────────────────────────────────────────────────
   Business User     T1(read), T3A(read), MX(read)
   Data Steward      T1(full), T2A(full), T2B(full), T3A(full), MX(full)
   Data Owner        Toàn bộ + nút Approve
   Developer / DBA   T1(read), T2B(full), MX(full)
   Admin             Toàn bộ + /admin/*

4. CONTEXT-SENSITIVE NAVIGATION
   ─────────────────────────────────────────────────────────────────
   Khi đang xem 1 Asset cụ thể (/assets/:id):
   → Hiển thị breadcrumb: Tài sản > [Domain] > [Tên asset]
   → Secondary nav (tab bar) thay cho việc dùng sidebar
   → Các action liên quan (Sửa, Đổi trạng thái, Xem Lineage)
      nằm trên header page, không nằm trong sidebar

   Khi đang xem 1 Term (/glossary/:id):
   → Breadcrumb: Thuật ngữ > [Domain] > [Tên term]
   → Tab bar: Định nghĩa | Quan hệ | Kỹ thuật | Phiên bản | Audit

5. SEARCH (Ctrl+K — Command Palette)
   ─────────────────────────────────────────────────────────────────
   Phím tắt Ctrl+K mở search overlay toàn cục
   Kết quả nhóm theo:
   · Tài sản dữ liệu (Data Assets)
   · Thuật ngữ (Glossary Terms)
   · Gần đây (Recent)
   · Phê duyệt đang chờ (My Pending)
